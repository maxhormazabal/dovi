# Changelog

All notable changes to this project are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
adheres to [Semantic Versioning](https://semver.org/).

## [0.0.1] - 2026-10-06

### Added

- `DocumentGenerator` and `DocumentReplicator` public API.
- `DoviDocument` data model with JSON and Markdown export.
- Generation and replication pipeline options.
- HTML, Markdown and JSON render backends; optional PDF (WeasyPrint) and DOCX (python-docx) backends.
- OpenAI-compatible LLM client.
- `dovi` command line interface with `generate` and `replicate` commands.
